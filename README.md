# 🏢 RealEstateFinder — Подборщик новостроек (Бизнес / Премиум)

Десктопное приложение на Python для быстрого поиска, фильтрации и оценки стоимости квартир в жилых комплексах бизнес- и премиум-класса на основе локальной базы данных Excel (`.xlsx`).

---

## ✨ Основные возможности

* **Загрузка актуальной базы Excel:** Валидация структуры таблицы (`15` обязательных колонок) с защитой от некорректных данных.
* **Гибкая фильтрация:** Поиск по городу, классу жилья (*Бизнес*, *Премиум*, *Все*), бюджету и желаемой площади квартиры.
* **Умное ранжирование (Smart Scoring):**
  * Приоритет отдается объектам, которые укладываются в заданный бюджет и имеют в линейке застройщика квартиры нужного метража.
  * Если точного попадания в бюджет нет, программа подбирает топ-3 ближайших варианта с расчетом минимальной суммы доплаты.
* **Расчет вилки стоимости:** Отображение ориентировочной цены «от и до» для заданной площади на основе минимальной и максимальной стоимости за 1 м².
* **Быстрая верификация:** Прямой переход из карточки ЖК на страницу источника (`source_url`) в браузере в один клик.
* **Автономная сборка:** Поддержка упаковки в единый исполняемый файл `.exe` для запуска на Windows без установки Python.

## 📊 Требования к структуре Excel-файла

Программа принимает файлы формата `.xlsx` или `.xls` (данные считываются с первого листа). Первая строка должна содержать строго следующие заголовки в формате `snake_case`:

| Колонка | Тип данных | Описание | Пример |
| :--- | :--- | :--- | :--- |
| `id` | Целое число | Уникальный порядковый номер ЖК | `1` |
| `city` | Строка | Город расположения | `Москва` |
| `complex_name` | Строка | Название жилого комплекса | `Дом 56` |
| `developer` | Строка | Наименование застройщика | `Галс-Девелопмент` |
| `district` | Строка | Район города | `Басманный` |
| `segment` | Строка | Класс недвижимости (`бизнес` / `премиум`) | `премиум` |
| `deadline` | Строка | Срок сдачи (`ГГГГ-QК` или `сдан`) | `2027-Q4` |
| `area_m2_min` | Дробное число | Минимальная площадь квартиры в ЖК (м²) | `34.5` |
| `area_m2_max` | Дробное число | Максимальная площадь квартиры в ЖК (м²) | `142.0` |
| `price_per_m2_min` | Целое число | Минимальная цена за 1 м² (₽) | `580000` |
| `price_per_m2_max` | Целое число | Максимальная цена за 1 м² (₽) | `890000` |
| `price_total_min` | Целое число | Минимальная стоимость лота в ЖК (₽) | `21500000` |
| `price_total_max` | Целое число | Максимальная стоимость лота в ЖК (₽) | `125000000` |
| `source_url` | Строка (URL) | Прямая ссылка на источник данных | `https://...` |
| `proof_quote` | Строка | Цитата со страницы для сверки цифр | `Квартиры от 34,5 м²...` |

> **Важно:** Числовые колонки не должны содержать пробелов, текстовых примечаний и символов валюты (`₽`).

## 🚀 Установка и запуск (для разработчиков)

### Предварительные требования
* Python **3.12 – 3.15**
* Менеджер пакетов **Poetry** (версии 2.0+)

### 1. Установка зависимостей
Откройте терминал в корневой директории проекта и выполните:

```powershell
poetry install
```

### 2. Запуск приложения
Запустить программу можно через зарегистрированный скрипт Poetry или напрямую как модуль:

```powershell
# Вариант 1 (рекомендуемый)
poetry run start-app

# Вариант 2
poetry run python -m real_estate_finder.main
```

## 📦 Сборка в автономный `.exe` (Windows)

Для создания единого исполняемого файла, не требующего установленного Python на компьютере пользователя, используется **PyInstaller**.

1. Убедитесь, что `pyinstaller` установлен в `dev`-зависимостях:
   ```powershell
   poetry add --group dev "pyinstaller@^6.22.3; python_version < '3.16'"
   ```

2. Выполните команду сборки:
   ```powershell
   poetry run pyinstaller `
       --noconfirm `
       --onefile `
       --windowed `
       --name "RealEstateFinder" `
       --paths "src" `
       --collect-all "customtkinter" `
       "src/real_estate_finder/main.py"
   ```

3. Готовый файл появится по пути `dist/RealEstateFinder.exe`.
